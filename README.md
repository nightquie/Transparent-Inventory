# Transparent Inventory

A simple Minecraft resource pack that makes the inventory background transparent.

## Features

- Transparent inventory background.
- Clean and minimal design.
- No additional mods required.

## Compatibility

Designed for Minecraft Java Edition 1.21.11 and newer.

## Installation

1. Download the resource pack from Releases.
2. Open Minecraft Java Edition.
3. Go to **Options → Resource Packs**.
4. Click **Open Pack Folder**.
5. Move the downloaded ZIP file into the folder.
6. Activate **Transparent Inventory**.
7. Click **Done**.

## Recommended settings

- Place the resource pack at the top of the resource pack list.
- No additional video settings are required.
